# Dataset

Place your own authorized face images in this folder.

Create a separate folder for each person.

Example:

dataset/
├── Person1/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── image3.jpg
│
├── Person2/
│   ├── image1.jpg
│   └── image2.jpg

Do not upload private face images or personal biometric data to a public repository.
